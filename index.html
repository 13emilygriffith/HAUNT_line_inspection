HAUNT line review

Caution: the 1D GHOST spectra were combined and normalized by an unvetted script written by Claude, so expect some mismatches with the synthesis. The HAUNT-star spectra are synthesized at R = 75,000 and the Sun at R = 56,000. Only the most prominent lines are labeled in each panel.
How to read the plots and use this page

Enter your name and choose an element. Each line window shows four panels: the HAUNT star (top) and the Sun (bottom), synthesized with Alex Ji's line list (left, blue) and the TSFitPy line list (right, orange; Gaia-ESO lines where available, VALD elsewhere, plus molecules above 4200 Å). Solid: full synthesis. Dashed: synthesis without the element. Black points: GHOST spectrum. Lower panels: how much the element absorbs (synthesis without the element minus full synthesis). Red labels mark the element's lines (grey: no visible effect); black labels name other lines.

Drag to zoom (all panels zoom together), double-click to reset. In one-at-a-time view, keys 1–6 choose a rating and ← → move between lines. Enter goes to the next line, also from the comment box (Shift+Enter for a new line in a comment). Ratings save as you go.
